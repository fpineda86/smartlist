# Smart List

Aplicación móvil de listas de compras inteligente con comparador de precios (Amazon/eBay).

**Eslogan**: "Find the cheapest, but the best".

**Meta**: Agilizar la decisión de compra mediante un algoritmo de Urgencia y comparación de costos en tiempo real.
